# VIX_PRICING
Stochastic Volatility Modelling &amp; VIX Pricing

This repository contains two projects in quantitative modeling:

Calibration of a Stochastic Local Volatility (SLV) model using the particle method (Guyon-Labordère) with Nadaraya-Watson kernel regression. The calibration reaches a mean absolute error of 12 bp on a flat 15% implied volatility surface.

Pricing of VIX futures and options in the two-factor Bergomi model using Gauss-Hermite quadrature, with an analysis of the impact of vol-of-vol and mean reversion on the VIX smile.
